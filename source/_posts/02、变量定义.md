<p>可以约定变量的初始类型，约定之后就不能更改类型</p>
<p>String、int、bool、double 等等</p>
<p>&nbsp;</p>
<p><strong>dymanic</strong> 定义变量，变量类型后续可随意更改</p>
<p>&nbsp;</p>
<p><strong>var</strong> 定义变量，根据第一次赋值时的类型进行约定，后续不能更改其他类型</p>
<p>&nbsp;</p>
<p>每个定义的变量都是一个对象，都有其内置的方法调用</p>
<p>&nbsp;</p>
<p><strong>const&nbsp;</strong>&nbsp;定义常量，初始化时必须进行赋值，赋值之后能不能进行更改。当定义为数组时，也不能修改里面数据&nbsp;</p>
<p>// const String name = '张三'</p>
<p>&nbsp;</p>
<p><strong>final&nbsp;</strong>定义的变量只能进行一次赋值。当定义为数组时，可以修改里面的数据。</p>
<p>// final String name;&nbsp; name = '123'</p>
<p>&nbsp;</p>
<p><strong>List&nbsp;</strong>数组</p>
<p>不规定数据类型：List names = [1, 'haha', false, 3];</p>
<p>规定数据类型：List&lt;String&gt; names = ['a', 'b', 'c']</p>
<p>添加数据 names.add('haha')</p>
<p>删除数据 names.remove('b')</p>
<p>数据过滤</p>
<div class="cnblogs_code">
<pre>names = names.<span style="color: #0000ff;">where</span><span style="color: #000000;">((name){
   </span><span style="color: #0000ff;">return</span> name != <span style="color: #800000;">'</span><span style="color: #800000;">a</span><span style="color: #800000;">'</span><span style="color: #000000;">; 
}).toList();</span></pre>
</div>
<p>&nbsp;</p>
<p>&nbsp;</p>
<p><strong>Set</strong> 集合，集合里面不能包含重复的项</p>
<p>不规定数据类型：Set names = {1, 'haha', false, 3};</p>
<p>规定数据类型：Set&lt;String&gt; names = {'a', 'b', 'c'}</p>
<p>单个集合添加 names.add('c')</p>
<p>多个集合添加 names.addAll({'z', 'f'})</p>
<p>&nbsp;</p>
