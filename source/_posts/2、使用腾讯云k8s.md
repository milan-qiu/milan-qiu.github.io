[1、先购买集群，后创建命名空间 test_app_namespace](https://console.cloud.tencent.com/tke2/cluster?rid=1)<br><br>

[2、后创建镜像仓库 my_repo](https://console.cloud.tencent.com/tcr/repository)<br><br>

3、本地登录腾讯云容器镜像服务 Docker Registry<br>
`docker login ccr.ccs.tencentyun.com --username=`<br><br>

4、配置好Dockerfile，打包镜像<br>
`docker build -t test_app_namespace/gin-service:1.0 -f ./Dockerfile .`<br><br>

5、docker本地试跑<br>
`docker run -d --name gin-service -p 8080:8080 test_app_namespace/gin-service:1.0`<br>
`docker run -d --name gin-service --net host test_app_namespace/gin-service:1.0`<br><br>

6、向 Registry 中推送镜像<br>
当前 imageId = test_app_namespace/gin-service:1.0<br>
`docker tag [imageId] ccr.ccs.tencentyun.com/test_app_namespace/my_repo:[tag]`<br>
`docker push ccr.ccs.tencentyun.com/test_app_namespace/my_repo:[tag]`<br>

7、可通过腾讯云手动部署

8、也可用 编写 deployment.yaml 用 kubectl 连接腾讯云部署
