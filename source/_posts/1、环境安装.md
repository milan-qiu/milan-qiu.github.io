<p>安装go</p>
<p>&nbsp;</p>
<p>下载安装地址：<a href="https://studygolang.com/dl" target="_blank">https://studygolang.com/dl</a></p>
<p>&nbsp;</p>
<p>设置国内镜像</p>
<div class="cnblogs_code">
<pre>go env -w GO111MODULE=<span style="color: #000000;">on
go env </span>-w GOPROXY=https:<span style="color: #008000;">//</span><span style="color: #008000;">goproxy.cn,direct</span></pre>
</div>
<p>&nbsp;</p>
<p>安装 goland</p>
<p>&nbsp;</p>
<p>下载地址：<a href="https://www.jetbrains.com/go/" target="_blank">https://www.jetbrains.com/go/</a></p>
<p>&nbsp;</p>
<p>通过start trial登录试用</p>
<p>&nbsp;</p>
<p>下载 FineAgent.jar</p>
<p>&nbsp;</p>
<p>点击 Help -&gt; Edit Custom VM Options ，末尾添加&nbsp;-javaagent:D:\\FineAgent.jar</p>
<p>&nbsp;</p>
<p>保存重启</p>
<p>&nbsp;</p>
<p>通过激活码激活，完成</p>
<p>&nbsp;</p>
<p>点击 file -&gt; settings -&gt; plugins，安装中文插件 Chinese (Simplified)</p>
<p>&nbsp;</p>
<p>测试运行</p>
<p>&nbsp;</p>
<p>新建hello.go</p>
<div class="cnblogs_code">
<pre><span style="color: #000000;">package main

import </span><span style="color: #800000;">"</span><span style="color: #800000;">fmt</span><span style="color: #800000;">"</span><span style="color: #000000;">

func main()  {
    fmt.Println(</span><span style="color: #800000;">"</span><span style="color: #800000;">hello world</span><span style="color: #800000;">"</span><span style="color: #000000;">)
}</span></pre>
</div>
<p>&nbsp;</p>
<p>编译二进制文件 go run hello.go 后可以直接运行二进制文件</p>
<p>&nbsp;</p>
<p>直接运行 go run hello.go</p>
<p>&nbsp;</p>
<h3>goland 2021.2 开启对泛型的支持</h3>
<div class="cnblogs_code">
<pre>go run -gcflags=-G=<span style="color: #800080;">3</span><span style="color: #000000;"> test.go
go build </span>-gcflags=-G=<span style="color: #800080;">3</span> test.go</pre>
</div>
