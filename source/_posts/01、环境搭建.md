<p>flutter官网sdk包：<a href="https://flutter.dev/docs/get-started/install" target="_blank">https://flutter.dev/docs/get-started/install</a></p>
<p>中文网包：<a href="https://flutter.cn/docs/get-started/install" target="_blank">https://flutter.cn/docs/get-started/install</a></p>
<p>&nbsp;</p>
<p>配置系统环境变量path：D:\flutterSDK\flutter\bin</p>
<p>&nbsp;</p>
<p>是否安装成功。命令行：flutter&nbsp;</p>
<p>&nbsp;</p>
<p>检查依赖是否安装：flutter docter</p>
<p>&nbsp;</p>
<p>安装android studio：<a href="https://r4---sn-i3belnll.gvt1.com/edgedl/android/studio/install/4.2.1.0/android-studio-ide-202.7351085-windows.exe?cms_redirect=yes&amp;mh=ei&amp;mip=185.245.41.50&amp;mm=28&amp;mn=sn-i3belnll&amp;ms=nvh&amp;mt=1624323705&amp;mv=u&amp;mvi=4&amp;pl=24&amp;rmhost=r3---sn-i3belnll.gvt1.com&amp;shardbypass=yes&amp;smhost=r3---sn-i3b7knsd.gvt1.com" target="_blank">https://developer.android.com/studio/index.html</a></p>
<p>&nbsp;</p>
<p>配置系统变量path：</p>
<p>&nbsp;%JAVA_HOME%\bin;</p>
<p>%JAVA_HOME%\jre\bin;</p>
<p>&nbsp;</p>
<p>添加系统变量JAVA_HOME：</p>
<p>C:\Program Files\Java\jdk-15.0.1</p>
<p>&nbsp;</p>
<p>启动android studio，打开空白java项目，安装依赖</p>
<p>&nbsp;</p>
<p>Android License 异常问题：</p>
<p>Configure -&gt; SDK manager -&gt; Android SDK -&gt; 勾选Android SDK Command-LINE tools(latest)</p>
<p>继续运行&nbsp;flutter doctor --android-licenses，一路y</p>
<p>&nbsp;</p>
<p>为flutter配置国内镜像源（windows）：配置系统变量</p>
<p>FLUTTER_STORAGE_BASE_URL: https://storage.flutter-io.cn<br />PUB_HOSTED_URL: https://pub.flutter-io.cn</p>
<p>&nbsp;</p>
<p>添加模拟器：AVD manager&nbsp; -&gt;&nbsp;</p>
<p><img src="https://img2020.cnblogs.com/blog/1680452/202106/1680452-20210630090602946-1611438291.jpg" alt="" width="705" height="554" loading="lazy" /></p>
<p>//要下载android内核</p>
<p>&nbsp;</p>
<p>查看当前模拟器：flutter emulators</p>
<p>运行模拟器：flutter emulators --launch &lt;模拟器名称&gt;</p>
<p>&nbsp;</p>
<p>vs code 安装扩展包：flutter</p>
<p>//会自动安装dart</p>
<p>&nbsp;</p>
<p>ctrl + shit + p -&gt; flutter:new application project (创建新项目)</p>
<p>&nbsp;</p>
<p>修改项目中，google仓库地址为阿里云地址：android -&gt; build.gradle</p>
