01-HTML基础

发表于 2020-01-17 更新于 2026-08-20
1、align对齐属性值:left、right、center、justify(伸展对齐) 2、空格：" " 3、文字展示形式： = = 斜体 = = 粗体 = 上标 = 下标 4

1、align对齐属性值:left、right、center、justify(伸展对齐)

 

2、空格："&nbsp;"

 

3、文字展示形式：

<i></i> = <em></em> = 斜体

<b></b> = <strong></strong> = 粗体

<sup> = 上标

<sub> = 下标

 

4、无序列表ul.li的type属性：disc = 圆点（默认），square =正方形 ，circle =空心圆

 

5、有序列表ol.li的type属性：1、a、A、i、Ⅰ(罗马数字1)

 

6、定义列表dl.dt.dd，dt列表标题，dd列表描述

 

7、图像标签：<img src="" alt="" />，alt为图像替代文本

 

8、超链接<a href="" target="" title=""></a>的

target属性：_self(本窗口)、_blank(新的窗口)、_top ( 框架结构用 )、_parent ( 框架结构用 )；

title属性：鼠标移动到超链接上面显示title信息

 

9、锚链接(同一页面)，<a href="#要跳转的锚名" name="锚名"></a>（a标签里面不一定要有内容，也可以起到定位的作用）

 

10、 锚链接(不同一页面) ， <a href="网页地址#要跳转的锚名" name="锚名"></a>（a标签里面不一定要有内容比如：<a name=""></a>，也可以起到定位的作用）

 

11、邮箱链接，<a href="mailto:邮箱地址"></a>

 

12、height: 50px;
    line-height: 50px; //行内文字垂直居中

 

13、margin: 0 auto; //外边距上下为0，左右自动，页面水平居中

 

14、padding: 0 0 0 0;//上 右 下 左 （顺时针方向）

 

15、opacity: 0.5;//透明度

 

16、border-radius: 20px; //圆角
