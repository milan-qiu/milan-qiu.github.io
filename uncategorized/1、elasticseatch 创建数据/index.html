put 创建 / 更新 index

PUT account/_doc/1
{
  "name":"明明",
  "age":18,
  "companies":[
  {
    "name":"one",
    "address":"beijing"
  }  
  ]
}


// 若id不存在就创建 account，指定id为1
// 若id存在就更新 account
// PUT 方法必须传id

 

post 创建 / 更新数据

POST user/_doc/1
{
  "name":"1"
}
// 传id时，用法与put一致

POST user/_doc/
{
  "name":2
}
// 不传id时，表示新增

 

post + _create 数据不存在就创建，存在就报错

POST user/_create/1
{
  "name":"1"
}
